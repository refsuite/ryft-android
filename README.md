# refsuite/ryft-android — `maven` branch

This is an **orphan branch** that hosts a static Maven repository for the
Refsuite fork of the Ryft Android SDK. It is served anonymously over
`raw.githubusercontent.com`, so consuming apps need **no credentials**:

```kotlin
repositories {
    maven { url = uri("https://raw.githubusercontent.com/refsuite/ryft-android/maven/") }
}
dependencies {
    implementation("com.refsuite.ryft:ryft-android:2.0.2-refsuite.1")
}
```

Do not edit by hand. It is regenerated by the publish step on the code
branches — see `DEVELOPMENT.md` on `main`. The SDK source lives on `main`.
